Source Image Assets in Unity
===
This editor plugin recognizes [Krita] and [OpenRaster] images as assets in Unity.

> KRA/ORA files are free alternatives to proprietary formats like PSD.

Use this repo to check the [documentation], [report bugs] or [ask questions] publicly. For customer support, you can also send a [private message].


KRaster Previewer
---
You can download the [free demo] first if you want, and upgrade later.

> Preview Krita and OpenRaster files directly.  
> Right-click assets and quickly generate a PNG for importation.


KRaster Importer
---
Please acquire the [full version] in the Unity Asset Store to support the developer!

> Import Krita and OpenRaster files directly, simplifying your workflow.  
> Assets auto-reimport every time you make changes.
